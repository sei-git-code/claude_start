# 分別タスク

`ストック.md` の各項目（S-01〜S-29）を振り分けるための手順とチェックリスト。分別が終わった項目は、ストック側から削除するか「分別済み」に印を付ける。

## 振り分け先

- **導入候補** → このリポジトリのカタログに追加する（`modules/<名前>/` 作成 + `CLAUDE.md` のカタログ追記）。導入は 1 項目ずつユーザー確認、実行して動作確認してから完了報告
- **参考として保管** → `reference/` にまとめる（既存の `reference/claude-code-monthly-survey.md` の新しい月の節に足すのが基本）。導入はしないが後で見返す価値がある
- **既存モジュールの更新** → すでに導入済みのモジュールの README や設定に反映する（例: モデル既定値、hook の追加）
- **破棄** → 重複、古い、根拠が薄い、このリポジトリの方針に合わない

## 判定基準（上から順に確認）

1. **重複か**: 既存の `modules/` や `reference/` にすでにあるか。あれば「既存モジュールの更新」か「破棄」
2. **一次情報で裏が取れるか**: 公式ドキュメント（code.claude.com/docs、platform.claude.com、anthropic.com）で確認できるか。取れない数値・日付は採用しない
3. **自分の環境で効くか**: Windows で動くか（例: zerdr は macOS/Linux 専用で不可だった）。プランや現行モデル設定（`"model": "sonnet"` 固定）と矛盾しないか
4. **安全か**: 外部の skill/plugin/MCP は中身を読んでから。パイプ実行（`curl | sh`）は避け、ダウンロード→確認→実行にする
5. **実行して確かめたか**: 記事のコマンド名・リポジトリ名は実在を確認する（過去に記事の記載と食い違った例が複数ある）
